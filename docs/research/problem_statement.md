# Problem statement

Cybersecurity researchers and defenders routinely combine vulnerability databases, ATT&CK knowledge, standards, vendor advisories, papers, logs, and local documents. Retrieval alone does not establish truth: an item can be relevant but unauthoritative, outdated, contradictory, poisoned, or incorrectly cited.

CyberSecRA-X investigates how an assistant can make evidence quality visible at claim level, reason over temporal and graph relationships, and abstain when support is insufficient.

The first increment operationalizes the research question as a measurable pipeline:

`retrieve → rank → correlate → verify → cross-check → score → explain → cite → abstain`
