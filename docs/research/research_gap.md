# Research gap

The project hypothesis is that many cybersecurity assistants optimize for answer fluency while under-reporting evidence quality. A useful system should evaluate not only answer relevance, but also:

- whether a claim is supported by the cited passage;
- whether the source is authoritative and temporally appropriate;
- whether two credible sources disagree;
- whether an identifier actually exists in the available evidence;
- whether abstention is correct when evidence is insufficient;
- whether retrieved documents attempt to override system instructions.

This is a proposed framing, not a claim that no prior system addresses these dimensions. A literature review and annotated benchmark are required before making novelty claims.
