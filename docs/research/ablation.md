# Ablation protocol

Implement and evaluate these configurations against the same frozen benchmark and source snapshot:

A. Provider answer without retrieval
B. Lexical retrieval
C. Hybrid retrieval
D. Hybrid + reranker
E. + source authority ranking
F. + temporal metadata
G. + graph relationships
H. + claim/citation verification
I. + contradiction detection
J. Full system with abstention

Do not fill missing cells with placeholders. Each configuration must produce a run artifact with code version, corpus checksum, model/provider configuration, seed, metrics, and failures.
